# MIRA Control — Rev.A

Рабочий каркас KiCad для самостоятельного создания схем управления MIRA: **140 листов A4**, включая 18 общих листов и 122 пустых подробных листа. Общие схемы, навигация и граница питания сохранены из проекта Rev.A. Электрические схемы с подробных листов удалены — их можно переносить, проверять и исправлять по одному. Печатная плата пустая.

## Открытие

Открой `MIRA_Control.kicad_pro` в KiCad 7 или новее. Для работы с компонентами выбери библиотеку `MIRA_RevA`: таблицы символов и посадочных мест уже подключены к этому проекту.

Все 140 листов уже включены в иерархию, формат — A4 в альбомной ориентации. На общих листах видны разделы MCU, FPGA, Communications, DAC stimulus, Matrix analogue interface и Power interface. В соответствующие подробные листы вставляй и проверяй схемы из полного проекта. Новые листы создавай в A4. У схемы и проекта ревизия A; имена компонентов и поля библиотеки заполнены на английском.

## Состав

- `MIRA_Control.kicad_sch` — общий корневой лист; из него открываются все разделы и 122 пустых подробных листа.
- `MIRA_Control.kicad_pcb` — пустая плата без контура, компонентов и проводников. Стек слоёв ещё не выбран.
- `libraries/MIRA_RevA.kicad_sym` — 136 определений УГО.
- `libraries/MIRA_RevA.pretty/` — 46 посадочных мест.
- `libraries/MIRA_RevA.3dshapes/` — 46 локальных STEP-моделей.
- `sym-lib-table`, `fp-lib-table` — локальные таблицы библиотек с путями `${KIPRJMOD}`.
- `docs/models/` — источники моделей, контрольные суммы и лицензионные сведения.
- `docs/EXTERNAL_POWER_INTERFACE.csv` и `.json` — плановый интерфейс питания и управления. Его физические узлы ещё не размещены на подробных листах; таблица служит ориентиром при заполнении каркаса.

На общем листе `0010_EXTERNAL_SUPPLIES` оставлены 17 виртуальных маркеров PWR_FLAG. Это служебные символы ERC, они не относятся к физическим компонентам, спецификации или плате. На 122 подробных листах нет компонентов, проводов, меток и прежних пояснений к собранным схемам.

УГО, посадочные места и модели скопированы из проекта управления Rev.A без изменения содержимого. Минимальный зазор меди в настройках платы и класса Default — **0,2 мм**. Это начальная настройка; правила питания и высокоскоростных линий нужно добавить по мере разработки.

Четыре STEP-модели с суффиксом `_Drawing_Model.step` упрощённые: HD3SS3220, WSON-8 Winbond, FBGA-96 Micron и SiTime SiT9121. Они построены по номинальным чертежам и не подтверждают производственные допуски.

RJ45 Amphenol RJE71-188-1412 требует выреза у края платы. Контур на `Dwgs.User` — ориентир для переноса в итоговый `Edge.Cuts`. У модели Pulse H5007NL есть расхождение между старым CAD и новым размерным чертежом; детали приведены в `docs/models/3D_MODEL_README.md`.

Сохраняй в Git схемы, плату, проект, таблицы и библиотеку вместе. Пользовательские настройки вида, резервные копии и временные файлы KiCad не нужны в коммитах.
