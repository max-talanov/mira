# Local 3D models

All 48 footprints reference models through `${KIPRJMOD}/libraries/MIRA_RevA.3dshapes/`. The STEP files and source/licensing records in model_manifest.json are copied from the updated MIRA Control Rev.A library.

Six models are nominal drawing models: HD3SS3220, Micron DDR3L FBGA96, SiTime SiT9121, Winbond WSON8 and the two new 0201 passives. They are package envelopes rather than manufacturer-certified tolerance models. The two 0201 models are original CC0 geometry; earlier models retain their documented licensing.
