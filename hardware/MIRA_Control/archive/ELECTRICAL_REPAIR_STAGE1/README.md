# MIRA Control — Rev B

Открывать **MIRA_Control.kicad_pro**. В проекте 7 функциональных групп:
MCU, INTERCONNECT, FPGA, DAC, MATRIX, ADC, PROTECTION.
22 электрических листа следуют подряд от100 до2200 с шагом100.
Физические обозначения начинаются с базы листа; многосекционный корпус
сохраняет одно обозначение на всех своих листах.

Подтверждённые ошибки связей, питания, АЦП и аппаратных разрешений исправлены.
Отдельный PDF объясняет новую схему и содержит журнал исправлений.
**Короткие микроамперные WRITE остаются блокирующим вопросом перед выпуском PCB.**
Низкоплечевая петля не ограничивает все ёмкостные токи DUT на первом фронте.
Подробности и необходимые требования: `docs/REPAIR_NOTES_RU.md`.

Локальные библиотеки используют пути относительно проекта; переносить папку целиком.
Ответный интерфейс MIRA_Power и токовый бюджет требуют согласования.
Сокетная 3D-модель приближённая по высоте и механике; см. `docs/CROSSBAR_SOCKET_3D.md`.
Архивные исходники/предыдущие отчёты в `archive` не являются активной схемой.
