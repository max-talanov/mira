# Моделирование канала AFE

Схема канала с пределом ±5 мА, рассчитанная в ngspice с моделью TI OPA197. Результаты — в [`../Моделирование.md`](../Моделирование.md).

## Как запустить

1. Установить ngspice: `sudo apt install ngspice`.
2. Скачать модель OPA197 (OPAx197 PSpice Model, файл SBOMA34D.ZIP) со страницы [ti.com/product/OPA197](https://www.ti.com/product/OPA197) и распаковать в `models/opa197/`, чтобы получился файл `models/opa197/OPAx197.LIB`.
3. Создать файл `.spiceinit` со строкой `set ngbehavior=psa` — режим совместимости с PSpice для моделей TI.
4. Запустить:

```bash
python3 channel_sim.py dc 1           # точность на пределе 1 (5 мА); пределы 1–4
python3 channel_sim.py pulse 2 47e-12 # импульс 0 → 2,5 В на пределе 2 с коррекцией 47 пФ
```

Модель TI не считает рабочую точку командой `.op`. Поэтому питание и уставка плавно нарастают от нуля, а всё считается переходным анализом.
