# Общая библиотека MIRA

Символы (`MIRA.kicad_sym`), посадочные места (`MIRA.pretty`) и 3D-модели (`3d/`), общие для всех плат. Проекты подключают библиотеку через `${KIPRJMOD}/../libraries/...`, у посадочных мест 3D-модели указаны так же.

## Детали

| Символ | Деталь | Корпус | LCSC | Выводы сверены по |
|---|---|---|---|---|
| MS9714 | Ruimeng MS9714, ЦАП 14 бит 125 млн отсч./с | TSSOP-28 | C5291387 | даташит Ruimeng V1.4, таблица выводов |
| OPA197xDBV | TI OPA197IDBVR, прецизионный ОУ | SOT-23-5 | C221351 | TI SBOS737C, Pin Functions (DBV) |
| TP2582-SR | 3PEAK TP2582-SR, сдвоенный ОУ, секции A, B и питание | SOIC-8 | C2902353 | 3PEAK Rev.A.2, Pin Configuration |
| TMUX6112 | TI TMUX6112PWR, 4 ключа SPST, четыре секции и питание | TSSOP-16 | C2673384 | TI, Table 5-1 (PW) |
| DG212B | Vishay DG212BDY-T1-E3, 4 ключа SPST, четыре секции и питание | SOIC-16 | C2673437 | Vishay 70040 Rev. J |

Посадочные места и 3D-модели — копии стандартных из KiCad 10. Размеры корпуса MS9714 сверены с чертежом из даташита: шаг 0,65 мм, корпус 9,6–9,8 × 4,3–4,5 мм.

У каждого символа есть поля MPN, Manufacturer и LCSC: по ним собирается BOM для JLCPCB.

У DG212B вывод 12 — VL, питание логики (5 В). У TMUX6112 вывод 12 не подключён, поэтому корпуса не взаимозаменяемы.
