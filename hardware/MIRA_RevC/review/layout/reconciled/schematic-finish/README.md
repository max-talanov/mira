# MIRA-01.01.00 / MIRA-01.02.00 — оформление схем

Исходный SHA — `059992528cd65e63e64f95be1293c36c252fba20`. Этот проход касается схем. Незавершённое уплотнение и функциональное размещение PCB описаны отдельно. [Остаток работ по PCB](../functional/README.md)

## Журнал

[Проверка по листам и компонентам](sheets.csv) содержит статус каждого активного листа, перечень references, сверку их наличия в PDF, выполненные изменения и оставшиеся кандидаты на проводное оформление. Для многосекционных символов при сверке учтены буквенные суффиксы. Проверка наличия обозначений не заменяет сплошную визуальную проверку наложений.

Изменены 22 активных листа. Добавлены 41 проводная связь между ранее раздельными группами и вручную переработаны сигнальные цепи на DDR3L, FX20 и в десяти ячейках разрешения VIN. На Crossbar сдвинуты разъём J10002 и блок сокета с R10001/R10002, формат уменьшен до 390 × 260 мм. На Power 300 исправлено размещение подписи R30012, которая в PDF сливалась с GND. [Проводные связи](local-wires.csv)

- [Цифровой узел, DDR3L и подтяжки](digital-ddr.png)

Промежуточный лист Control 5300 Module Interface свёрнут в лист разъёмов. Бывший 5400 стал 5300; J540001 → J530001, J540002 → J530002. Сохранены UUID символов и footprints. У обоих компонентов из пути удалён один уровень иерархии. Обозначения, имена NC-цепей и метаданные пути синхронизированы на PCB. Прочие PCB совпадают с исходными файлами побайтно. Все координаты, повороты и стороны установки сохранены. [Оглавление](../sheets.csv) · [UUID и полная таблица перенумерации](../renumbering.csv)

## Проверки и остаток

Свежие XML netlist совпадают по составу компонентов и множествам выводов каждой цепи после нормализации двух обозначений и пути листа разъёмов. Проверка CH48 подтверждает 48 электродных цепей, 96 входов АЦП, 48 DAC, 144 отвода формовки, 48 управлений разрядом и 64 вывода сокета.

На трёх проектах KiCad 10.0.5: 0 ERC, 0 нарушений DRC, 0 расхождений схемы с PCB. Несоединённые цепи относятся к предстоящей трассировке. [Отчёты](../validation/)

Поэлементное оформление частично завершено. Кандидаты на локализацию отмечены в журнале, в том числе Supervisor Interface, USB-C, Service DAC and Servo, Forming Interlock, Host Link Watchdog и группы Analog Isolation. Общие опоры квартетов и переходы между листами остаются именованными. Привязка распределённой развязки и полная визуальная проверка на уровне каждого компонента остаются открытыми.
