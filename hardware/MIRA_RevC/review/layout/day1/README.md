## Разъёмы и ключевые компоненты

`connector-map.csv` содержит **9 строк-пар**, каждая с координатами обеих половин, углами/сторонами в файле и общем виде, точкой pin 1 и векторами datum→1 и 1→3. `verification.json` содержит фактические координаты контактов 1, 2, 3 после сохранения и перечитывания PCB.

- Control J400…J407: **B.Cu, 180°**; Power J4901…J4908: **F.Cu, 0°**. В общем виде от pin 1 контакт 2 слева на 2.54 мм, контакт 3 снизу на 2.54 мм. Все 118 контактов восьми пар совпали по XY, все цепи совпали с учётом исходного CORE_SENSE_P на Power/J4902.17 (Control/J401.17 — CORE1V0).

Проверены цепи всех 140 контактов. Паяльные площадки S и P имеют разные расстояния от оси: ±2.85 и ±2.70 мм, поэтому их проекции различаются на 0.15 мм. Они не являются точками контакта при сочленении; совмещены оси корпусов и порядок контактов, а не ряды паяльных хвостов.

| Плата | Компоненты | Площадки | DRC до: геометрия | DRC после: геометрия | Unconnected до/после в отчёте |
|---|---:|---:|---:|---:|---:|
| Control | 2333 | 10426 | 1: отсутствует контур | 0 | 499 / 499 |

Дорожек и медных зон **0/0** на всех платах. 499 — ограниченный отчёт KiCad (не полное количество ratsnest-связей), и набор показываемых рёбер может меняться при перемещении. Это исходная неразведённость, не результат разрыва цепей: полное соответствие net→pad проверено отдельно. Нулевой DRC не означает законченную расстановку: staging вне Edge.Cuts остаётся неразмещённым.

DRC выполнялся в изолированных копиях с одинаковыми исходными `.kicad_pro`, `.kicad_dru` и библиотеками. Исключения/отключённые проверки исходного проекта сохранены, перечислены в `drc-summary.json`. В частности, Control игнорирует PTH/NPTH внутри courtyard, и существующие специальные правила для BGA требуют отдельного инженерного рассмотрения. `--schematic-parity` не запускался; проверка электрической неизменности не является новой независимой полной сверкой схемы. `.kicad_pro` рабочего проекта не изменены.

## Артефакты и воспроизведение

- `assembly-top.png` — обзор и боковой разрез; показывает ключевые реальные позиции, не весь staging.
- `connector-map.csv`, `verification.json`, `geometry.json` — данные из перечитанных PCB.
- `*-before-drc.json`, `*-after-drc.json`, `drc-summary.json` — сопоставимые отчёты.
- `MIRA_60_Day_PCB_Plan_RU.pdf` — копия найденного плана из `~/Downloads`.
- `build_draft.py` — **пересобирает PCB из указанного исходного SHA**, запускать только для намеренного воспроизведения (заменит последующие ручные правки). Нужен Python с модулем KiCad `pcbnew`.
- `render_review.py` — Python + Pillow, рисует из `geometry.json`.
- `check_drc.py /path/to/kicad-cli` — сравнивает исходный SHA и текущие PCB в `/tmp/mira-layout-drc`, рабочие проекты не сохраняет.
