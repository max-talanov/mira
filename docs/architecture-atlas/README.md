# MIRA Architecture Atlas 4.3 — скачивание и запуск

Интерактивный атлас объясняет работу плат MIRA Power и Control: питание, контроллеры, интерфейсы, матрицу, измерения и защиту. Внутри есть функциональные диаграммы, анимация сигналов, схемотехнические фрагменты и режим презентации. Интерфейс и пояснения — на русском.

**[Скачать MIRA_Architecture_Atlas_4.3.zip](https://github.com/max-talanov/mira/raw/refs/heads/main/docs/architecture-atlas/MIRA_Architecture_Atlas_4.3.zip)** — около 5,3 МБ; после распаковки около 40 МБ.

## Как открыть

1. Скачайте ZIP по ссылке выше. Если открыли страницу ZIP на GitHub, нажмите **Download raw file** / кнопку скачивания.
2. **Полностью распакуйте архив** в обычную папку. Не запускайте HTML прямо из окна архиватора.
3. Откройте папку `MIRA_Architecture_Atlas`.
4. Откройте файл **`index.html`** в Firefox или Chrome. Обычно достаточно двойного щелчка; если открывается редактор, выберите «Открыть с помощью» → браузер.

Установка, интернет, локальный сервер, Node.js, Python, KiCad и API-ключ для просмотра не нужны. Папки `css`, `js`, `data` и `sources` должны оставаться рядом с `index.html`; переносить только HTML-файл нельзя.

GitHub показывает исходный HTML как текст. Для работы атласа нужно скачать архив и открыть распакованный файл на компьютере.

## Что открывать внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | Сам атлас: интерактивные диаграммы и презентация |
| `guide.html` | Реплики ведущего и действия для показа |
| `MIRA_Presentation_Script_RU.pdf` | Сценарий выступления для печати |
| `START_HERE_RU.txt` | Краткая памятка по управлению |
| `README.md` | Подробное руководство, структура данных и инструкции по редактированию |

Нажмите **«Презентация»** для обзора из 24 эпизодов, примерно на 10–15 минут. Рассказ переключается вручную кнопками «Назад» / «Далее» или стрелками. Для самостоятельного изучения нажмите блок, затем «Открыть модуль и его историю». Нажатие на связь показывает имена цепей и выводы из включённых схем KiCad.

## Если скачали весь репозиторий

Через **Code → Download ZIP** на главной странице репозитория скачивается весь MIRA. Распакуйте его, откройте `docs/architecture-atlas/`, затем отдельно распакуйте находящийся там `MIRA_Architecture_Atlas_4.3.zip`. Далее откройте `MIRA_Architecture_Atlas/index.html`.

В клонированном репозитории этот же ZIP находится по пути `docs/architecture-atlas/MIRA_Architecture_Atlas_4.3.zip`.

Пример для Ubuntu, из папки с уже скачанным архивом:

```bash
unzip MIRA_Architecture_Atlas_4.3.zip
xdg-open MIRA_Architecture_Atlas/index.html
```

Если диаграммы не появились, сначала проверьте, что распакован весь архив и папки `data`, `js` и `css` находятся рядом с `index.html`.

## Версия схем в атласе

Это оригинальный пакет **4.3.0**, подготовленный **22 октября 2026 года**, без изменений содержимого. В нём 77 листов из более ранних снимков Control и Power; источники перечислены в `RELEASE.json` внутри архива. Обновления схем конца октября автоматически в атлас не попадают.
