## Изменение схемы

В Control, лист `900_FPGA_ETHERNET_AND_MCU_INTERFACE`, сигнал `MCU_FPGA_SCK_F` перенесён с U500.AB12 на U500.Y11. Y11 — `IO_L11P_T1_SRCC_13`, положительный clock-capable вход bank 13, 3.3 V. AB12 освобождён и отмечен No Connect. Обычный AB12 мог использоваться при oversampling SPI; новый вариант допускает выделенный тактовый путь без такого архитектурного ограничения. Это не подтверждение timing closure.

На листе `800_FPGA_DDR3L_AND_REFERENCE_CLOCK` уточнены целевая скорость DDR и режим отключённого chip select. Электрические соединения DDR сохранены. Все остальные pin-to-net пары Control сохранены, Power и BOM не изменены. PCB не обновлён; при его разработке использовать Y11, не AB12.

Сверены 484 + 176 + 96 + 54 функции выводов и наборы контактных площадок четырёх посадочных мест. Полная метрология посадочных мест в эту проверку не входит. У FPGA промышленное температурное исполнение; у указанной Micron нет суффикса IT: диапазон case temperature 0…95 °C, при температуре выше 85 °C нужен удвоенный refresh. Промышленный диапазон всей платы из исполнения FPGA не следует.

| 13 | IO3V3 / 3.3 V | Ethernet, SPI с MCU; 22 |

Проверены все 37 VCCO-контактов. Нет повторного назначения пользовательских контактов или постороннего 3.3 V интерфейса в DDR-банках. Зарезервированы внешние VREF H18/K14 и D15/C20; `fpga-all-484-pins.csv` включает также питание, конфигурацию и NC.

| Сигнал | Вывод FPGA | Условие |
| --- | --- | --- |
| SYSCLK 200 MHz | J19/H19 | MRCC bank 15; LVDS_25 input, DIFF_TERM FALSE, существующее внешнее согласование |
| DDR CK | K17/J17 | Настоящая P/N пара; окончательная пригодность PHY — через MIG |
| DDR DQS byte 0 / 1 | F18/E18 / B21/A21 | DQS-пары bank 16; DQ/DM остаются в byte groups T2/T3 соответственно |
| FT_CLK | W19 | MRCC bank 14; план 100 MHz |
| PHY_RXC | W11 | MRCC bank 13; RGMII до 125 MHz |
| MCU_FPGA_SCK_F | Y11 | SRCC bank 13; план SPI 25 MHz |

Цель DDR3L: **400 MHz / 800 MT/s, PHY 4:1**, UI 100 MHz, CL6/CWL5, x16, row15/col10/bank3. Выбор учитывает предел DDR3L для Artix-7 speed grade −2; скоростная маркировка памяти −107 не задаёт допустимую частоту контроллера. Номиналы C801/C802=100 nF, R800–R803=10 kΩ и R804=100 Ω сохранены: входной LVDS AC-coupled, смещение от DDR1V35/2. Внешнее согласование требует `DIFF_TERM FALSE`; электрические уровни/jitter на реальной плате ещё предстоит подтвердить.

**CS# U800.L2 на GND допустим только при соответствующем режиме MIG** (Controller Chip Select Pin Disable). Это не дефект, требующий немедленной перетрассировки. ZQ — 240 Ω на GND, RESET# — pull-down 10 kΩ. Частоты, минимальные параметры и ограничение температурного refresh записаны в `../../../fpga/digital-interfaces/mig-settings.json`.

## STM32 / FMC и остальные AF

FMC соединён с U200 SDR SDRAM, а связь STM32 ↔ FPGA выполнена через SPI1 и буферы. Все **39 линий FMC — AF12**, включая PC4=SDNE0 и PC5=SDCKE0. Проверены реальные соединения через последовательные резисторы, а не только сходство имён цепей. SDRAM bank 1, стандартный адрес 0xC0000000, x16, row13/col10, четыре внутренних банка.

Также сверены QSPI (6 контактов), SDMMC1 (6), SPI1 (3) и USART2 (2): всего 56 AF-контактов. PA4 используется как GPIO chip select; PA5/PA6/PA7 — SPI1 AF5. Таблицы основаны на официальных ST pin-data XML, включая общий для H745/H747 файл GPIO IP. Число контактов проверено по LQFP176, не по другому корпусу. Настройка HAL/clock tree, cache/MPU и временные параметры SDRAM в прошивке этим не подтверждаются.

## Проверки и воспроизведение

`python3 scripts/verify_digital_interfaces.py` — **1650 проверок пройдено**. Скрипт экспортирует новую native netlist, сверяет с данными производителей и точным допустимым изменением двух контактов. `--netlist` позволяет повторно проверять сохранённый XML. ERC KiCad 10.0.8: Power 61 лист, Control 43 листа, **0 ошибок / 0 предупреждений**, новых исключений нет; прежние настройки проверок стиля сохранены.

В `validation/regression/` сохранены результаты восьми регрессионных сценариев: сигнальные защиты, запуск, аварийные блокировки, последовательность питания, обесточенные входы, распределённое питание, электрические и геометрические соединения разъёмов. Все завершились успешно; геометрический сценарий требовал Python-модуль KiCad `pcbnew`. Исторические baseline-файлы не переписаны: старые проверки нормализуют только два явно объявленных изменения SPI, а новая проверка требует уже новое соединение.
