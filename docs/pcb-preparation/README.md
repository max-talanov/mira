## Карта незавершённых вопросов

«Закрыт по схеме» означает подтверждённую связность и оформление. Испытания перечислены отдельно и не заменяются нулевым ERC.

| ID | Текущее состояние | Следующее действие и критерий закрытия |
|---|---|---|
| I01 | Закрыт по схеме: 8 пар, 118 контактов, MPN/footprint/3D назначены | Геометрию и токовую квалификацию продолжать в I06/B03 |
| I02 | Частично: MATRIX_INHIBIT_N подключён к STOP Power | Проверить таблицу состояний, защёлку, повторное разрешение и обрыв. LOW должен аппаратно снять разрешения |
| I03 | Закрыт по связности: HOST_RESET_N → J4901.15/J400.15 → U100.33 | Поведение при отключении питания остаётся в I07 |
| I04 | Добавлен аппаратный таймер 5400 и защёлка LINK_READY_H | Реализовать heartbeat 50 мс / разрыв ≤100 мс, проверку содержания обмена и новый ARM; измерить реакцию |
| I05 | Открыт: роль AUX2V5 не определена | Назначить нагрузку либо пересмотреть необходимость шины и условие ALL_RAILS_PG |
| I06 / B03 | Частично: разъёмы и местные вводы выбраны, расчёт обновлён | Проверить размещение, стойки, токи ветвей/GND, падения и температуру при совместной нагрузке |
| I07 | Частично: reset подтянут к SYS3V3, домены разрешения разделены | Проверить AON/SYS3V3/IO3V3 во всех состояниях, Ioff, обратное питание и сброс |
| I08 / B06 | Открыт | Подтвердить VTT source/sink, DDR_VREF tracking/noise, возврат и порядок включения у потребителя |
| B01 | Открыт: токи FPGA — допущения | Получить XPE для частот, ресурсов, активности I/O и температуры; сверить память/интерфейсы |
| B02 | Частично: MIRA.05 фиксирует пределы аппаратуры и отдельные режимы; паспорт матрицы отсутствует | Получить допустимые V/I/t/C/Q/E образца; квалифицировать динамику и затем утвердить рабочие режимы |
| B04 | Открыт: рампы частично условные | Проверить реальный запуск N15/PROG_N15 и FPGA при Vin min и предельной нагрузке |
| B05 | Открыт | Проверить источники, дроссели, ключи, LDO, защиту, энергию отказа, нагрев и шум |
| E01–E06 | Закрыты как причины сообщений текущего ERC | Подробности и ограничения — в отчёте ERC |
| E07 | Новая проверка воспроизводима | Старым пользовательским отчётам не приписывается неподтверждённое происхождение |

Для B03 есть конкретное незакрытое условие: если весь расчётный ток IO3V3 пойдёт через единственный контакт зоны DDR, MCU или ADC/AFE, оценка с неравномерностью составит около 1,934 А при проектном бюджете 1 А. Это консервативный сценарий, а не установленный ток каждой ветви. Разводка должна обеспечить проверенное распределение; при невозможности потребуется изменить количество контактов/топологию.

Для B04 условная рампа N15 5 мс даёт около 0,618 А против нижней статической оценки порога OCP 0,513 А. Поэтому запас модуля 2 А сам по себе не закрывает запуск. Фактическую рампу, sequencing и динамику защиты необходимо проверить до выпуска PCB.

## История и воспроизводимость

Первоначальная сверка схем опиралась на `b457c20`, а её отчёты опубликованы в `24b4428`. Исходные [хеши](interboard-sources.json), пользовательские ERC `.rpt`, `messages.json` и `report-metadata.json` сохранены без изменений. [Снимок документов до обновления](history/day1-day2-baseline/README.md) хранит прежние выводы и расчёт; они не описывают текущую схему.

Проверки текущих схем: KiCad CLI **10.0.7**, **0 ошибок / 0 предупреждений / 0 исключений** на каждой плате. Два прежних правила оформления `four_way_junction` и `single_global_label` отключены; это явно отражено в отчёте. 6686 записей ref–pin–net вне заменённых разъёмов сохранены относительно `c72edb2`.

```bash
python3 scripts/verify_distributed_power.py
python3 scripts/verify_high_load.py
python3 scripts/verify_power_budget.py
```

Последний скрипт проверяет расчёт и сохранённые значения XLSX. Первые два требуют KiCad CLI. Нулевая выдача ERC не подтверждает рабочие токи, устойчивость, нагрев, EMC или изготовление.
