## Закрытие причин первоначальных сообщений

| ID | Причина | Выполненное исправление / граница вывода |
|---|---|---|
| E01 | Обратная связь U1903 | Соединены 1↔2 и 6↔7. Подтверждены сети и отсутствие прежних сообщений |
| E02 | 85 сообщений вне сетки | Исправлено оформление соединений; в текущей выдаче таких сообщений нет |
| E03 | 34 предупреждения о VSS | У шести типов аналоговых символов отрицательные выводы названы VSS_NEG, сохранены номера и power_in. GND остаётся отдельной сетью; 32 прежних исключения удалены |
| E04 | Имена сетей скрытых выводов | Уточнено представление выводов питания и имён сетей; текущие конфликты устранены |
| E05 | 10 нераспознанных источников | Уточнена модель источников ERC. На Control только один контакт каждого входного питания моделирует внешний источник, параллельные вводы пассивны |
| E06 | #FLG0102 | Неподключённого флага в текущем ERC нет. Неподтверждённая причина старого пользовательского сообщения не объявляется доказанной |
| E07 | Происхождение и область проверки | Новые отчёты привязаны к версии KiCad, составу файлов и хешам. Происхождение старых `.rpt` остаётся таким, как записано в исходных метаданных |

Включены `ground_pin_not_ground`, `footprint_filter`, `simulation_model_issue`. Два прежних правила оформления **`four_way_junction` и `single_global_label` отключены**. Нулевые счётчики относятся к этому опубликованному набору правил; формулировка «все возможные проверки включены» неверна.

VSS_NEG не соединяется с землёй ради подавления предупреждений. Исправлено название отрицательного питания, а не его электрическая функция. Конкретные проверки 34 выводов и отдельных GND приведены в [отчёте разъёмов/ERC](../connectors-erc/README.md).

## Сохранённая исходная проверка

В пользовательских отчётах было: Control **4 ошибки + 118 предупреждений**, Power **11 ошибок + 13 предупреждений**, всего **146 сообщений**. Файлы `.rpt`, [все сообщения](messages.json) и [метаданные с хешами](report-metadata.json) в этой папке сохранены побайтово. Старый полный разбор находится в [истории](../history/day1-day2-baseline/erc/README.md).

Для повторной проверки из корня репозитория: `python3 scripts/verify_distributed_power.py`. Проверка электрических правил не моделирует устойчивость, нагрев, ток контактов, пуск, шум и защиту при отказе. Незавершённые проверки находятся в [общем перечне](../README.md#карта-незавершённых-вопросов).
