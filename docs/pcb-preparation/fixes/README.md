## Что остаётся открытым

| Вопрос | Состояние и следующий шаг |
|---|---|
| I01 / B03 | Логическая распиновка согласована; выбрать реальную пару разъёмов, геометрию, покрытие и подтвердить ток/падение. Generic footprint не является выбранным изделием. |
| I02 | Соединение STOP добавлено; проверить таблицу состояний, защёлку и повторный запуск, включая обрыв соединения. |
| I03 | Выход сброса выведен; динамическое поведение при пропадании SYS3V3 остаётся частью I07. |
| I04 | Вход назначен; включить его обработку в требования к прошивке PM. |
| I05 | AUX2V5 и её участие в ALL_RAILS_PG не пересмотрены; нужен определённый потребитель либо решение об отключении резервной шины. |
| I06 / B01–B03 | Нужны режим FPGA/XPE, предельная нагрузка матрицы и выбранная пара разъёмов. |
| I07 | Подтяжка сброса исправлена; проверить все комбинации AON/SYS3V3/IO3V3 и пути обратного питания. |
| I08 / B06 | Нужны требования и проверка VTT source/sink, sense, DDR_VREF, возврата и последовательности. |
| B04 | Пуск N15/PROG_N15 не исправлен изменением номиналов: нужны реальная рампа, нагрузка и последовательность EN. |
| B05 | Проверки защиты, теплового режима, дросселей, ключей и допусков остаются открыты. |
| ERC | Проверить исключения, отключённые тесты и синхронизацию библиотек. |
| Зависимости | Полная автономность четырёх внешних стандартных 3D-моделей этим кандидатом не подтверждена. |

Предварительный XLSX описывает исходный сценарий до этих исправлений; его токи и результаты не следует считать пересчитанными для кандидата. Новый буфер также должен войти в бюджет.

## Данные для окончательных решений

1. FPGA: частоты, ресурсы/проект, активность I/O, температура либо согласованный расчётный предел.
2. Матрица: число одновременно активных линий, ток на линию, напряжения, длительность и скважность импульсов.
3. Конструкция: платы в стеке или жгут, расстояние/длина, ограничения по габаритам.

Источники для текущей проверки: [ADG5412](https://www.analog.com/media/en/technical-documentation/data-sheets/adg5412_5413.pdf), [74LVC1G17](https://www.nexperia.com/products/analog-logic-ics/logic/buffers-inverters-transceivers/buffers/serie/74lvc1g17).
