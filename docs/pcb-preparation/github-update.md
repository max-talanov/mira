# Перенос исправлений запуска и аварий в GitHub

Используйте `prepare-github-branch.sh` **из корня нового архива**:

```bash
bash ~/Downloads/MIRA_RevA_Distributed_Power/prepare-github-branch.sh /home/dima54/Projects/mira
```

Скрипт проверяет origin, чистое дерево и идентичность bundle/patch, импортирует базу `f8565ef` от 28 октября из bundle и применяет суммарный `startup-fix.patch` отдельным коммитом в `mira-fault-hardware-20261029`. Требуется настроенная Git-идентичность. Повторный запуск принимает уже применённый тот же patch; другую существующую ветку не перезаписывает. `main` и удалённые ветки не изменяются. Не применяйте суммарный patch поверх предыдущей его версии.

Содержимое обновления: блокировка запуска AON/EN/MATRIX, исправление EN_VTT, обратная связь PC14 и таблица 15 шин; новый лист 5400 с аппаратным heartbeat timeout, защёлкой первого импульса, reset host и PC15. Отчёты: `startup/`, `sequencing/`, `fault-review/` рядом с этим файлом. Изменение электрических соединений включает 14 новых компонентов; firmware/PCB и стендовые измерения остаются открытыми.

После проверки diff и схем пользователь может отдельно выполнить:

```bash
git push -u origin mira-fault-hardware-20261029
```

Автоматической публикации в этой работе нет. Старый bundle отдельно не содержит исправлений 29 октября; необходим суммарный patch из этого же архива.
