# Техническое задание MIRA

Версия ТЗ: 0.0.1 · 2026-11-20

Статусы пунктов:
- **решено** — можно опираться;
- **предв.** — рабочее значение, нужно подтвердить;
- **открыто** — ещё не решено.

## 1. Назначение

Универсальная платформа для исследования мемристорных кроссбаров разных типов. Она должна уметь:
- читать и программировать ячейки;
- формовать ячейки;
- выполнять умножение вектора на матрицу (VMM);
- работать со спайковыми моделями.

Кроссбары ставятся на свои сменные платы. Основная электроника от типа кроссбара не зависит.

| 2.5 | Размеры: материнская ≈ 215 × 170 мм, AFE ≈ 110 × 90 мм, Crossbar ≈ 60 × 60 мм, Zynq-модуль ≈ 60 × 60 мм | предв. |

## 3. Каналы

| | Требование | Статус |
|---|---|---|
| 3.1 | 64 канала: 4 карты AFE по 16. Прибор работает и с меньшим числом карт | решено |
| 3.2 | Все каналы одинаковые и без роли. Роли BL, WL, NL задаёт плата Crossbar и программа | решено |
| 3.3 | Состояния канала: свой уровень 1, свой уровень 2, земля, отключён (Hi-Z), разряд через резистор. Все переключаются FPGA синхронно с импульсами | решено |
| 3.4 | Рабочий диапазон ±2,5 В | предв. |
| 3.5 | Аппаратно канал выдерживает и выдаёт до ±5 В, питание каналов около ±6 В | предв. |
| 3.6 | Пределы тока: 3–4 предела, от ~10 нА до ±25 мА | предв. |
| 3.7 | Подача напряжений на любой набор каналов одновременно | решено |
| 3.8 | Выходной каскад канала у нижнего края карты. Путь до сокета ≈ 50–60 мм | предв. |
| 3.9 | Точность установки напряжения и измерения тока | открыто |

## 4. Импульсы

| | Требование | Статус |
|---|---|---|
| 4.1 | Минимальная длительность 1 мкс, обычно длиннее. Короче 20 нс не нужно | решено |
| 4.2 | Импульс формирует быстрый ключ 4:1 перед усилителем канала: два своих уровня ЦАП на канал и земля. ЦАП задаёт только амплитуды, 32 канала ЦАП на карту | решено |
| 4.3 | Тайминг задаёт FPGA с шагом не грубее 10 нс | предв. |
| 4.4 | Импульсы на нескольких каналах синхронны | решено |

## 5. Измерения

| | Требование | Статус |
|---|---|---|
| 5.1 | Точное медленное измерение при постоянных напряжениях. АЦП с мультиплексором по 16 каналам карты, 16 бит. Полный опрос карты ≈ 16 мкс, карты работают параллельно | предв. |
| 5.2 | **Осциллограф тока на всех 64 линиях** во время импульсов, все линии синхронно | решено |
| 5.3 | Осциллограф: 12 бит, 20–40 MSPS, полоса несколько МГц | предв. |
| 5.4 | Запись окна вокруг импульса в память FPGA карты и выгрузка после импульса. Окно не меньше 10 мкс | предв. |
| 5.5 | Видимый ток во время импульса — от сотен нА. Меньшие токи меряются медленным путём до и после импульса | предв. |
| 5.6 | Напряжение в режиме осциллографа — на нескольких линиях через мультиплексор | предв. |
| 5.7 | Сколько линий напряжения смотреть одновременно | открыто |

## 6. Карта AFE

| | Требование | Статус |
|---|---|---|
| 6.1 | 16 каналов: уровни ЦАП, драйвер, датчик тока с пределами, ключ подключения | решено |
| 6.2 | Усилитель канала одновременно задаёт напряжение и меряет ток: пределы тока — резисторы в его обратной связи (40 Ом, 4 кОм, 400 кОм, 40 МОм). Компоненты — в [`hardware/AFE/Компоненты.md`](../hardware/AFE/Компоненты.md) | предв. |
| 6.3 | Осциллограф: 16 быстрых усилителей тока, 2 восьмиканальных быстрых АЦП, небольшая FPGA с памятью | решено |
| 6.4 | Места под осциллограф разводятся всегда, а паять их можно по мере надобности | решено |
| 6.5 | FPGA карты сама обслуживает ЦАП и АЦП и связана с Zynq несколькими быстрыми последовательными линиями плюс общий тактовый сигнал и запуск. Это экономит контакты слота | предв. |
| 6.6 | EEPROM для опознания карты и её калибровки | предв. |
| 6.7 | Свои линейные стабилизаторы (LDO) аналогового питания на карте | предв. |

## 7. Формовка

| | Требование | Статус |
|---|---|---|
| 7.1 | Отдельная карта, до ±10 В, с ограничением тока | решено |
| 7.2 | Одна ячейка за раз, через три общие шины к сокету | предв. |
| 7.3 | Аппаратная блокировка: адреса BL, NL и WL не совпадают, разрешение снимается при любом отказе | предв. |
| 7.4 | Ключи каналов выдерживают ±10 В на линии во время формовки | предв. |

## 10. Питание

| | Требование | Статус |
|---|---|---|
| 10.1 | Вход 24 В, допустимо 18–30 В, защита от переполюсовки и перенапряжения | предв. |
| 10.2 | Карта питания раздаёт промежуточные шины. Конечные стабилизаторы стоят у потребителей | решено |
| 10.3 | Промежуточные шины: дежурная 3,3 В (AON), цифровая ≈ 5 В, аналоговая ≈ ±7 В, ±15 В для формовки. ±15 В заводятся и в слоты AFE: от них питаются ключи подключения, которые выдерживают ±10 В формовки | предв. |
| 10.4 | Супервизор класса STM32G0: включение шин, телеметрия, watchdog | предв. |

## 11. Защита

Защиты работают аппаратно и не зависят от прошивки.

| | Требование | Статус |
|---|---|---|
| 11.1 | Матрица запитана только при общем разрешении: шины в норме, watchdog жив, нет отказов, кнопка STOP не нажата | решено |
| 11.2 | Отказ по току на каждом канале с защёлкой. Отказ снимает разрешение | предв. |
| 11.3 | Маски каналов: канал не подключается к линии без явного разрешения | предв. |
| 11.4 | Переключение режимов по схеме «разомкнуть, потом замкнуть» | предв. |

## 13. Отложено

Вернуться к этим пунктам после первой рабочей версии:
- отдельные линии обратной связи по напряжению (Кельвин) до сокета;
- режим «задать ток».
