# Техническое задание MIRA

Версия ТЗ: 0.0.1 · 2026-11-20

Статусы пунктов:
- **решено** — можно опираться;
- **предв.** — рабочее значение, нужно подтвердить;
- **открыто** — ещё не решено.

## 1. Назначение

Универсальная платформа для исследования мемристорных кроссбаров разных типов. Она должна уметь:
- читать и программировать ячейки;
- формовать ячейки;
- выполнять умножение вектора на матрицу (VMM);
- работать со спайковыми моделями и обучать кроссбар по правилу STDP прямо в приборе.

Кроссбары ставятся на свои сменные платы. Основная электроника от типа кроссбара не зависит.

| 3.7 | Подача напряжений на любой набор каналов одновременно | решено |

| 3.9 | Точность установки напряжения и измерения тока | открыто |

## 4. Сигналы на каналах

| | Требование | Статус |
|---|---|---|
| 4.1 | На любой канал можно подать сигнал произвольной формы, заданный пользователем: импульсы, пилы, синус, ступени, последовательности спайков | решено |
| 4.2 | Самая короткая деталь сигнала — 1 мкс, обычно длиннее. Фронты короче 20 нс не нужны | решено |
| 4.3 | У каждого канала свой быстрый ЦАП (от ~10 млн отсчётов/с), форму на лету подаёт FPGA карты. Каналы независимы и синхронны | решено |
| 4.4 | Точные уровни задаёт тот же быстрый ЦАП с поправочной таблицей канала. Таблица измеряется заранее точным АЦП и применяется в момент задания значения: при загрузке сигнала, в Zynq или в FPGA карты. Задержки поправка не добавляет. Место под отдельный 16-битный ЦАП на плате остаётся про запас | решено |
| 4.7 | Быстрые ЦАП 16 каналов карты сидят на двух общих шинах по 8 и обновляются по очереди внутри каждых 100 нс. Выходы работают параллельно, а сдвиг обновления между каналами постоянный и известный, до 87,5 нс. Программа его учитывает. Каналы одной операции FPGA ставит на одну позицию шины, порядок переключений задаёт явно | решено |
| 4.5 | Тайминг задаёт FPGA с шагом не грубее 10 нс | предв. |
| 4.6 | Сигналы на разных каналах синхронны | решено |
| 4.8 | Напряжения можно менять во время опыта по результатам измерений (запись с проверкой, STDP). Быстрые решения принимает Zynq или FPGA карты, а не ПК: USB добавляет сотни мкс | решено |
| 4.9 | STDP: формы спайков хранятся в памяти FPGA карты для каждого канала и запускаются командой Zynq с шагом 100 нс. На ячейке пре- и постспайки складываются, поэтому разность напряжений на ячейке может быть вдвое больше напряжения одного канала | предв. |

## 5. Измерения

| | Требование | Статус |
|---|---|---|
| 5.1 | Точное медленное измерение при постоянных напряжениях. АЦП с мультиплексором по 16 каналам карты, 16 бит. Полный опрос карты ≈ 16 мкс, карты работают параллельно | предв. |
| 5.2 | **Осциллограф тока на всех 64 линиях** во время импульсов, все линии синхронно | решено |
| 5.3 | Осциллограф: 12 бит, 20–40 MSPS, полоса несколько МГц | предв. |
| 5.4 | Запись окна вокруг импульса в память FPGA карты и выгрузка после импульса. Окно не меньше 10 мкс | предв. |
| 5.5 | Видимый ток во время импульса — от сотен нА. Меньшие токи меряются медленным путём до и после импульса | предв. |
| 5.6 | Напряжение в режиме осциллографа — на нескольких линиях через мультиплексор | предв. |
| 5.7 | Сколько линий напряжения смотреть одновременно | открыто |
| 5.8 | FPGA карты непрерывно передаёт в Zynq токи всех 16 каналов с точного АЦП с задержкой не больше ~10 мкс. Это нужно моделям нейронов и STDP | предв. |

## 6. Карта AFE

| | Требование | Статус |
|---|---|---|
| 6.1 | 16 каналов: уровни ЦАП, драйвер, датчик тока с пределами, ключ подключения | решено |
| 6.2 | Усилитель канала задаёт напряжение на линии, меряя его прямо на линии через отдельный ключ. Ток считается по напряжению на пределе вместе с его ключом: 1 кОм, 20 кОм, 2 МОм, 200 МОм, сопротивление ключа калибруется. Схема и моделирование — в [`hardware/AFE/Моделирование.md`](../hardware/AFE/Моделирование.md), компоненты — в [`hardware/AFE/Компоненты.md`](../hardware/AFE/Компоненты.md) | предв. |
| 6.3 | Осциллограф: 16 быстрых усилителей тока, 2 восьмиканальных быстрых АЦП, небольшая FPGA с памятью | решено |
| 6.4 | Места под осциллограф разводятся всегда, а паять их можно по мере надобности | решено |
| 6.5 | FPGA карты сама обслуживает ЦАП и АЦП и связана с Zynq несколькими быстрыми последовательными линиями плюс общий тактовый сигнал и запуск. Это экономит контакты слота | предв. |
| 6.6 | EEPROM для опознания карты и её калибровки | предв. |
| 6.7 | Свои линейные стабилизаторы (LDO) аналогового питания на карте | предв. |
| 6.8 | Точный и быстрый выходы тока берутся с одного разностного усилителя: к точному АЦП — через RC-фильтр. Отдельного инструментального усилителя нет, его ошибку от синфазного напряжения убирает калибровка | предв. |
| 6.9 | Ключи на линии (подключение, обратная связь, разряд) — с гарантированно малой утечкой, ими управляет FPGA напрямую. Ключи пределов — дешёвые, управляются сдвиговыми регистрами | предв. |

## 10. Питание

| | Требование | Статус |
|---|---|---|
| 10.1 | Вход 24 В, допустимо 18–30 В, защита от переполюсовки и перенапряжения | предв. |
| 10.2 | Карта питания раздаёт промежуточные шины. Конечные стабилизаторы стоят у потребителей | решено |
| 10.3 | Промежуточные шины: дежурная 3,3 В (AON), цифровая ≈ 5 В, аналоговая ≈ ±7 В, ±15 В для формовки. ±15 В заводятся и в слоты AFE: от них питаются ключи подключения, которые выдерживают ±10 В формовки | предв. |
| 10.4 | Супервизор класса STM32G0: включение шин, телеметрия, watchdog | предв. |

| | Требование | Статус |
|---|---|---|

| 11.2 | Отказ по току на каждом канале с защёлкой. Отказ снимает разрешение | предв. |
| 11.3 | Маски каналов: канал не подключается к линии без явного разрешения | предв. |
| 11.4 | Переключение режимов по схеме «разомкнуть, потом замкнуть» | предв. |
